# Day 01 – Personal web site on GitHub Pages

## The task

Create a personal web site hosted on GitHub Pages and submit it by opening an
issue on the course repository.

## What I did

1. Created a GitHub account (username `Michal-azimov`).
2. Created a public repository named `Michal-azimov.github.io`. A repository
   with that exact name is automatically published by GitHub Pages.
3. Added an `index` page with an introduction about myself, using AI to help
   write the content and the design.
4. Checked that the site is live at <https://michal-azimov.github.io>.
5. Opened the submission issue on the course repository:
   [Day01-Michal azimov (#33)](https://github.com/Code-Maven/wis-python-course-2026-10/issues/33).
6. The lecturer replied: *"Good start, but please add some more content and
   improve the design."* I updated the site with more content and a better
   design and replied on the issue.
